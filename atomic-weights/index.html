Molar Mass

Standard atomic weights of the elements

The values this site uses for every calculation: the abridged standard atomic weights from IUPAC, for all 118 elements.

An atomic weight is the average mass of the atoms of an element as it is found in nature, compared with one twelfth of an atom of carbon-12. It has no unit. The same number, read in grams per mole, is the molar mass of the element. The table below is the abridged list published by the Commission on Isotopic Abundances and Atomic Weights (CIAAW) of IUPAC, in which each value is given to five significant figures. We read it on 12 November 2026.

The uncertainty column shows how far the value can vary. For most elements it is tiny. For a few, such as lithium, boron and sulphur, natural samples differ enough that the last digit is not fixed. "None" means the element has no stable isotopes and so no standard atomic weight; the calculator does not work out formulas that contain those elements. Why the values are what they are is explained on the page where atomic weights come from.

Using the table

  1. Find each element of your formula.
  2. Multiply its atomic weight by the number of its atoms.
  3. Add the results to get the molar mass in g/mol.

For school sums a rounded value is usually expected: 1 for hydrogen, 12 for carbon, 16 for oxygen, 35.5 for chlorine. Use what your textbook or question paper prints.

Source: CIAAW, Abridged Standard Atomic Weights, ciaaw.org. Element names are spelled as IUPAC spells them, except that sulphur is written the Indian way.
